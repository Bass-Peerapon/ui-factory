# 005: แก้หน้าที่ generate ไม่ให้ดูเป็น AI slop

วันที่ 2026-10-07 · สถานะ: เสร็จ

## ที่มา

หลัง 004 ผู้ใช้ยังเห็นว่าหน้าที่ได้ดูเป็นงาน AI จึงสร้างหน้าจริงผ่าน pipeline 2 โจทย์ (คลินิกทันตกรรม, ร้านอาหารไทยไฟน์ไดนิ่ง) แล้วเทียบกับ slop rules ของ impeccable (`crates/live/assets/antipatterns.json`) เจอ 5 กลุ่ม

| อาการ | สาเหตุ |
|---|---|
| กล่องรูปเปล่าขนาดใหญ่ หน้าดูเหมือน wireframe | ไม่มีภาพจริง |
| หัวข้อกึ่งกลางทุก section, grid การ์ด 3 ใบซ้ำ (ราคา, รีวิว, ข้อมูลติดต่อ), icon tile เหนือหัวข้อ | renderer ใช้ template เดียวทุก block |
| Hero ไม่มีปุ่ม, ฟอร์มลอยกลางหน้า, CTA band ซ้ำกับฟอร์ม, FAQ และราคาอยู่ก่อนส่วนที่อธิบายสินค้า | composer ไม่คุมลำดับและไม่ใส่ action |
| ชื่อแบรนด์ไม่ตรงกันในหน้าเดียว (Ari Dental Studio, Index Dental Clinic) | fill แต่ละ block แยกกันโดยไม่มีข้อมูลร่วม |
| copy ลอยๆ ("รสชาติแห่งความวิจิตรบรรจง") และร้านอาหารไม่มีเมนู | ไม่มี block เมนู และ lint ไม่จับ buzzword |

## สิ่งที่ทำ

| เรื่อง | ทำอะไร |
|---|---|
| ภาพจริง | ขั้น `illustrate` หลัง fill เรียก `gemini-3.1-flash-image` วาดภาพจาก `imageAlt` ของ Hero, ImageText และ Gallery สูงสุด 7 ภาพต่อหน้า ทีละ 3 ภาพ prompt บอกภาพอื่นในหน้าเพื่อไม่ให้ซ้ำ ไฟล์เก็บที่ `data/images/` แบบ content-addressed และ spec เก็บแค่ URL ตั้ง `GEMINI_IMAGE_MODEL=` เป็นค่าว่างเพื่อปิด |
| Fact sheet | ก่อน fill เรียก fast model หนึ่งครั้งเพื่อกำหนดแบรนด์, ที่ตั้ง, ติดต่อ, คน, สินค้าและราคา, หลักฐาน และสิ่งที่มีแค่ที่นี่ เก็บใน `Frame.Facts` ทุก block และทุกหน้าใน flow เติมจากชุดเดียวกัน |
| Renderer | หัวข้อชิดซ้ายและ subtitle อยู่ข้างๆ, FeatureGrid เป็นพื้นเดียวแบ่งช่องและ icon อยู่ข้างหัวข้อ, Pricing เป็นคอลัมน์บนเส้นแบ่งแทนการ์ดยกตรงกลาง, รีวิวไม่มีกล่อง, ContactForm สองคอลัมน์, ContactInfo เป็นรายการ, Team ไม่มีวงกลมตัวอักษรย่อ, ตารางเปรียบเทียบไม่มีกรอบ |
| PriceList | block ใหม่สำหรับเมนูและรายการบริการ จัดด้วยตัวอักษรและเส้นจุดนำ composer ถูกบอกให้ใช้กับร้านอาหาร คาเฟ่ ซาลอน สปา และคลินิก |
| Normalize | Hero ที่ไม่มีปุ่มได้ปุ่มหลัก, หน้าที่มีฟอร์มตัด CTA band ออก, ContactForm ที่ไม่มีช่องได้ช่อง ชื่อ เบอร์ และข้อความ, หน้าที่มี Hero เรียงเป็น เรื่อง หลักฐาน ราคา เปรียบเทียบ คำถาม ติดต่อ (หน้างานที่ไม่มี Hero คงลำดับเดิม) |
| Lint | จับ buzzword ทั้งไทยและอังกฤษ และรูปประโยค "ไม่ใช่แค่ X แต่คือ Y" ตามกฎ marketing-buzzword และ aphoristic-cadence ของ impeccable ถ้าเจอจะให้ fill เขียนใหม่ |
| ฟอนต์ | Shadcn (ค่าเริ่มต้น) และ Linear เปลี่ยนจาก Geist และ Inter เป็น IBM Plex Sans Thai ส่วน Vercel คง Geist ไว้เพราะเป็นตัวตนของแบรนด์ |

## ผลวัด

- สร้างหน้าใหม่ 4 หน้าและ flow 1 ชุด ทุกหน้ามีภาพจริง ชื่อแบรนด์ตรงกันทั้งหน้าและทั้ง flow และ Hero มีปุ่ม
- `make audit` บนหน้าที่สร้างจริง: dental 0, restaurant 1, SaaS 4 ลดเหลือ 1 (ฟอนต์ Inter ของโปรเจกต์ที่สร้างก่อนเปลี่ยนฟอนต์)
- `make audit` บน fixtures 24 เฟรม: 9 เหลือ 7 คือพื้นครีมของ Editorial, Warm Editorial, Friendly และ Geist ของ Vercel
- เวลา: หน้าเดียวประมาณ 30 ถึง 50 วินาที (fill 9 ถึง 10 วินาที, ภาพ 2 ถึง 7 ภาพ), flow 3 หน้าบนมือถือ 80 วินาที

## ข้อจำกัด

- ภาพใช้ quota ของ Gemini image model และเพิ่มเวลาต่อ turn ถ้ารูปไม่สำเร็จจะคงภาพตัวอย่างพร้อมคำบรรยาย
- ProductGrid, BlogList และ Team ยังไม่มีภาพ
- โปรเจกต์ที่สร้างก่อนหน้านี้ยังเก็บ theme และฟอนต์เดิม
- ยังไม่ได้รัน `make eval` รอบใหม่
